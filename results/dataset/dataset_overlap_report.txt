Note
   Overlap of this size is unlikely to be plagiarism between dataset
   authors; the more probable explanation is that both collections drew
   on the same upstream sources. The consequence for evaluation is the
   same either way, which is why the check is worth running on any pair
   of datasets before one is described as independent of the other.
