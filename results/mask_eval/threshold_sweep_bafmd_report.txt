How to read this

   The cross-fitted figure is the result. The threshold is chosen on one
   random half of the data and scored on the other, twenty times in both
   directions, so it never sees the labels it is judged on. That is what
   recalibration would actually be worth on unseen data from this
   population.

   The oracle figure is NOT an achievable result. It picks the threshold
   that maximises macro F1 on the very data it then reports, which no
   deployment can do. It is included only as the ceiling: no threshold
   choice on this data can beat it.

   If the cross-fitted figure sits close to the oracle, the threshold is
   stable and recalibration transfers. If it sits far below, the best
   threshold is an artefact of whichever half it was fitted on and
   recalibration is not the answer.

Limits

   A threshold is fitted and evaluated on halves of the SAME dataset, so
   this measures transfer across a random split, not across populations.
   It does not show that a threshold tuned here would suit a different
   deployment; it shows how much of the deployed loss on THIS population
   is attributable to threshold placement rather than to ranking.

   Recalibration cannot exceed what the ranking supports. The AUC above
   bounds every row in this table.
